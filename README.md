I'm a multidisciplinary technology professional from **Kenya** with a background in **GIS, software development, cybersecurity, networking, and data analytics**.

I enjoy turning ideas into practical digital products — from social platforms and healthcare systems to geospatial applications, dashboards, automation tools, and business platforms.

My approach combines **software engineering, infrastructure, security, data, and user experience** to build solutions that are not only functional, but also scalable and maintainable.

# 🏗️ Development Philosophy

I believe good software should be:

**🧠 Thoughtful** — solve the actual problem, not just the technical one.

**🔐 Secure** — security should be considered from the beginning.

**📈 Scalable** — architecture should leave room for growth.

**🎨 Usable** — functionality means little if users cannot use it comfortably.

**🛠️ Maintainable** — clean code and clear architecture matter.

**🌍 Impactful** — technology should ultimately make something better.
